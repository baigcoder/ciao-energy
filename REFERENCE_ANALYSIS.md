## Implementation Interpretation
The strongest recreation strategy is not to imitate individual HTML blocks. It is to reconstruct:
1. a master scroll timeline
2. one persistent WebGL product scene
3. a data-driven flavor state system
4. synchronized HTML typography
5. controlled background/theme interpolation
6. accessible non-WebGL fallbacks

## Fidelity Priorities
Highest:
- product scale/placement
- scroll behavior
- flavor transitions
- typography
- navigation composition
- black/white visual language

Medium:
- micro-lines
- tiny labels
- iconography

Lowest:
- 1px spacing differences that do not alter visual hierarchy
